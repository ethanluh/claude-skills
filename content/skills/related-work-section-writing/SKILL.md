# Related-work section writing

## Placement check (do this first)
Related work goes in one of two places — the choice depends on whether prior
work is prerequisite knowledge or comparison material, not on style:
- **Folded into the introduction** if the reader needs that context to
  understand the contribution at all.
- **Standalone section** (typically after the intro, before methods) if the
  comparison is easier once the reader already knows the paper's own
  approach — this is the default case this skill is written for.

If drafting from scratch and it's unclear which applies, ask: can a reader
understand what's novel here without first knowing what came before? If no,
fold it into the intro instead.

## Drafting / review checklist

1. **Thematic grouping, not a citation list.** Group prior work by topic or
   methodology, optionally chronological within each theme to show the
   field's evolution. One paragraph per citation is a failure mode, not a
   section.
2. **Detail scales with proximity to the contribution.**
   - General background: one clause + citation, no elaboration.
   - Closely related work: 1-3 sentences of actual explanation.
   - Work very close to the paper's own approach: an explicit sentence on
     how it differs — not just what it did.
3. **Evaluative, not descriptive.** Each cited line of work should carry an
   implicit or explicit drawback — what it doesn't do, where it falls short
   — not just a summary of its method. The section should read as an
   argument for why the new approach is necessary, not a survey.
4. **Explicit closing gap-statement — non-negotiable.** The last paragraph
   must name the gap in knowledge directly and position the paper's
   contribution against it. Never leave novelty to be inferred from the
   preceding paragraphs.
5. **Length discipline.** Standard conference format: roughly one page.
   If it's running long, that's a signal to re-group thematically rather
   than trim sentences — an exhaustive per-paper survey is the wrong shape
   at any length.
6. **Citation-as-noun anti-pattern (style lint).** Reject constructions like
   "In [12], researchers show..." — name the authors instead ("Smith et al.
   show..."). Use "studies" as the referent noun, not "papers." Use "et al."
   for 3+ authors.
7. **Prose, not disconnected citation-sentences.** Read the section start to
   finish: does it flow as connected argument, or is it separable into
   independent one-citation units that could be reordered without loss? If
   the latter, it isn't grouped thematically enough — return to check 1.

## When reviewing an existing draft
Run checks 1, 4, and 6 first — thematic grouping, the gap statement, and the
citation-as-noun pattern are the fastest tells for "this is a list, not an
argument." Only move to 2, 3, 5, 7 once those three pass.
