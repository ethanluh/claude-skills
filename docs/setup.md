# Setup

1. Clone the repo:
   ```
   git clone <repo-url>
   cd <repo-name>
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Run the dev server:
   ```
   npm run dev
   ```
4. Run the test suite:
   ```
   npm run test
   ```
5. To pull in current skill content from a local BigBrain checkout:
   ```
   npm run sync:skills
   npm run build:manifest
   ```
